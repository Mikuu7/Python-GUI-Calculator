Python GUI Calculator

Name: John Micko R. Dela Vega 

Project Description

Python GUI Calculator is a simple calculator application developed using Python and Tkinter. It provides a graphical user interface that allows users to perform basic mathematical operations such as addition, subtraction, multiplication, and division.

Features
- Addition
- Subtraction
- Multiplication
- Division
- Clear button
- Backspace button
- User-friendly graphical interface

Technologies Used
- Python
- Tkinter
